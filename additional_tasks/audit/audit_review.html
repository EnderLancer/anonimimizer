Перевірка персональних даних у рішеннях ЄДРСР

Це кандидати для ручної перевірки. Упевнено визначені службові імена й реквізити приховано. Фільтр «Категорія даних» дозволяє переглядати потенційні персональні, лише службові або всі фрагменти. Службові фрагменти показано разом із причинами виключення; неоднозначні випадки залишено для перевірки серед потенційних персональних. У діагностичному режимі raw перетинні фрагменти показано окремо.

Оцінки зберігаються у браузері, коли він дозволяє локальне сховище. Експортуйте їх у JSON для надійного збереження. Звіт працює локально без зовнішніх ресурсів.
